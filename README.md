## Project Structure

This repository contains the complete implementation and test verification for all 5 milestones of the COM-501 assignment:

| File | Description | Course Outcome & Bloom's Level |
|---|---|---|
| `milestone1.py` | Single e-waste collection estimation (input, type casting, slicing, arithmetic) | CO1 (BL3) |
| `milestone2.py` | Mixed collection processing with catalogue, while loop, sets, validation, volume bonus | CO2 (BL4) |
| `milestone3.py` | OOP modeling with `EWasteCollection` class, class attribute, methods, `__len__()` | CO3 (BL4) |
| `recycling_utils.py` | Module providing calculation utilities, default/keyword arguments, `math.ceil()` | CO4 (BL4) |
| `main.py` | Driver script utilizing `recycling_utils.py` and higher-order function `generate_metric` | CO4 (BL4) |
| `milestone5.py` | File I/O (`|` delimited), separate exception handling (`ValueError`, `KeyError`, `FileNotFoundError`), type debugging | CO5 (BL5) |
| `recycling_records.txt` | Persistent text file storing completed collection summaries | CO5 (BL5) |
